KDE 30th Birthday at TechFarms
==============================

A static page: open index.html in a browser, or upload the whole folder
to any web host / wiki that serves plain HTML.

Files
  index.html    the page (countdown + 3D confetti logic is inline at the bottom)
  three.min.js  three.js r149 (MIT licence), used for the confetti background
  konqi.png     Konqi artwork

Notes
  - Countdown targets Wednesday, October 14, 2026 at 6:00 PM in the
    visitor's local time. Change START near the bottom of index.html to adjust.
  - Fonts (Fredoka, Noto Sans) load from Google Fonts; offline it falls back
    to system fonts.
  - Visitors with "reduce motion" enabled see the confetti standing still.
